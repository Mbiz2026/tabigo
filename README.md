# タビゴ(TABIGO)— 旅英語 パーソナル学習アプリ

「海外旅行で店員とも現地の人とも話せるようになる」ことをゴールにした、
ユーザー専用の英語学習Webアプリ。半年〜1年で日常会話レベルを目指す。

## 設計方針(チャットでの合意事項)

- ユーザープロフィール: 読める/発音できるが「意味がわからない」語・熟語が多い。
  知識を口から出す反射訓練と、句動詞・熟語の意味の穴埋めが二本柱(比率 約7:3)
- 学習時間は日によってバラバラ → 毎回「今日は何分?(3/10/20分)」から始まる可変メニュー
- 怠惰対策: 日数カウント(ストリーク)は採用しない。
  - サボっても何も失われない設計(復習キューが自動調整されるだけ)
  - 「旅の進行」で継続を可視化(出発→到着→街歩き→現地の人と仲良くなる)
  - 3ヶ月ごとの録音定点観測・変動報酬
- 題材はすべて旅行×雑談(場面会話+現地の人とのスモールトーク)

## 現在のファイル

- `index.html` — 毎日のトレーニングアプリ本体(第2リリース)。
  - スパイラル方式: 瞬間英作文SRS+チャンク(句動詞・旅行語・雑談表現)SRSを
    毎日全レベル混合で出題。フェーズ制ではなく難度だけが上がる
  - ホーム画面の主役は「反射速度グラフ」(言えるまでの秒数の中央値推移、目標3.0秒)
  - 可変メニュー: 3分(復習のみ)/10分(+新規+リスニング)/20分(+シャドーイング)
  - コース選択: ミックス(既定)/はなす(英作文集中)/きく(リスニング集中)/
    ドライブ(画面を見ない自動音声ドリル。日本語→考える間→英語×2、SRS非干渉)
  - 診断結果をシード: 落とした語彙(refund, view, change等)を最優先出題、
    リスニングは0.85倍速から自動加減速(正解+0.02/不正解-0.03)
  - 行動設計: アンカー設定(if-thenプラン)、21時以降は復習のみ、
    時間が来たら気持ちよく終了、変動報酬(35%でミニストーリー/現地フレーズ)、
    全カードに「出題理由」を一行表示
  - 8週目に「英語の質問を聞いて英語で返す」モードが自動解禁(翻訳回路からの脱却)
  - 週=旅の停留地(機内→入国→ホテル→…)。週テーマに沿って新規表現が初出し、
    以後は混合プールに合流して卒業しない
- `diagnose.html` — 実力診断テスト(第1リリース)。5パート約15分。
  - ことば(単語・熟語の意味 / 基礎・中級・句動詞の3バンド)
  - ひきだし(日→英の想起)
  - 瞬間英作文(言えるまでの秒数を計測)
  - きく(速度耐性 0.7x〜1.2x、Web Speech APIのTTS使用)
  - 文のかたち(会話文型の穴スキャン)
  - 結果は端末のlocalStorageに保存。「結果コード」(JSON)をチャットに
    貼り付けてもらい、それを元にカリキュラムを生成する

## 品質維持の仕組み(モデル非依存)

将来どのモデルが作業しても品質が揃うよう、判断を手順書に固定し、機械検証を挟む:

- `CLAUDE.md` — 全モデル共通の憲法(大原則・不可侵事項・ユーザープロフィール・現在地)。
  **移行後はリポジトリのルートに置くこと**
- `docs/add_content.md` — 教材追加の手順書(スキーマ・英文品質基準・レベル定義・
  5〜12週目のテーマ固定・週あたりの必須構成)
- `docs/modify_app.md` — アプリ修正の手順書(localStorage不可侵リスト・設計原則
  チェックリスト・旧データテスト・スモークテスト項目)
- `docs/roleplay.md` — 月1ロールプレイの進行形式・レベル調整規則・講評テンプレート
- `docs/roleplay_log.md` — ロールプレイの定点観測記録
- `scripts/validate.mjs` — 教材データの機械検証。
  `node scripts/validate.mjs index.html` で ERROR 0件になるまで公開・コミット禁止

## ホスティング

本番はGitHub Pages(tabigo移行後: https://mbiz2026.github.io/tabigo/ )。
`sw.js`(オフライン対応)、`manifest.webmanifest`+アイコン3種(PWA=ホーム画面から
全画面起動する普通のアプリとして動作)を同梱。
Claude Artifactでの配信は保存領域が消える事象が実地で確認されたため廃止予定。
学習データは端末内保存(localStorage+IndexedDB二重化)+バックアップコード。

## 技術メモ

- 依存なしの単一HTML。スマホのブラウザで動作、ビルド不要
- 音声はWeb Speech API(speechSynthesis)。英語音声が無い端末ではスキップ可能
- 次フェーズ: 診断結果 → カリキュラム生成 → 毎日のトレーニング画面(SRS内蔵)

# 教材追加の手順書(どのモデルもこの通りに実行する)

対象ファイル: `train.html`(リポジトリ版)と Artifact 版の両方。
所要: 1週分の教材 = 文10・チャンク3〜6・リスニング2〜4・シャドーイング1セット。

## 手順(この順番を変えない)

1. `CLAUDE.md` と本ファイルを最後まで読む
2. `train.html` 内の `コンテンツバンク` セクション(`/* ====== コンテンツバンク ====== */` から
   `/* ====== 状態管理 ====== */` の直前まで)だけを編集する。**このマーカーコメントは
   検証スクリプトが依存しているので消さない・変えない**
3. 下記スキーマと品質基準に従ってデータを追記する
4. `WEEK_THEME` に追加した週のテーマを追記する(これを忘れると検証でERROR)
5. `node --check` でJS構文を確認 → `node scripts/validate.mjs train.html` でERROR 0件を確認
6. ブラウザ相当の動作確認: 追加した週まで `currentWeek()` が進んだ状態を想定し、
   新規カードとして出題されるか(SENTのwk条件)を目視でロジック確認
7. Artifact版(bodyのみ形式)にも同じ変更を反映し、**既存URLに再公開**(CLAUDE.md参照)
8. コミット・プッシュ
9. ユーザーへ報告: 「第◯週のテーマ」「追加した文の例3つ」「追加チャンクの例3つ」を
   3〜5行の日本語で。専門用語なし

## データスキーマ(フィールドを増減しない)

```js
// SENT(瞬間英作文)
{id:"s41", wk:5, lv:2, ja:"日本語(話し言葉)", en:"English sentence.", alt:"別解 でもOK(無ければ空文字)", q:"英語で聞かれる形(無ければ空文字)"}

// CHUNK(かたまり)
{id:"c37", kind:"phr|word|talk", pri:0, en:"英語表現(句動詞は 〜 を使用可)", ja:"意味", ex:"実際の使用例文", exJa:"例文の和訳"}

// LISTEN
{id:"l17", text:"読み上げる英文", q:"日本語の設問", ch:["選択肢1","選択肢2","選択肢3"], a:正解のindex}

// SHADOW
{id:"sh5", title:"場面名", lines:[{en:"...", ja:"..."} ×4行]}

// STORY(ご褒美) / TIP(ご褒美)
{id:"st5", title:"英語タイトル", text:"50〜80語の英文", ja:"あらすじ(日本語2〜3文)"}
{id:"t9", en:"フレーズ", ja:"解説(なぜ自然か・いつ使うか)"}
```

ID規則: SENT=s+2桁連番, CHUNK=c+2桁, LISTEN=l+2桁, SHADOW=sh+数字, STORY=st+数字, TIP=t+数字。
**既存IDの変更・削除・再利用は禁止**(ユーザーの学習履歴がIDに紐づいている)。

## 1週分の必須構成

- SENT 10文: **lv1〜lv4 を各1文以上含む**(検証でERROR)。lv4は必ず「現地の人との
  雑談」文にする(店員向け定型文はlv4にしない)
- CHUNK 3〜6枚: 句動詞(phr)を最低1枚含める
- LISTEN 2〜4問
- SHADOW 1セット(4行の対話。うち2行はユーザーが言う側の行にする)
- STORY/TIP: 任意(4週に1本程度追加)

## 英文の品質基準(ここがモデル間の品質差が出る場所。厳守)

1. **実際に旅行者・現地人が口にする自然な口語**のみ。教科書英語禁止。
   - 短縮形を使う: I'm / don't / it's(I am / do not は禁止)
   - 注文は Can I get 〜? を基本形にする(May I 〜? は使わない)
   - How are you? への返しに Fine, thank you. のような定型は使わない
2. 語彙は高頻度語(NGSL上位2000語相当)+句動詞が中心。難単語で格好をつけない
3. 文の長さの目安: lv1≤6語 / lv2≤9語 / lv3≤11語 / lv4≤14語(検証でWARN)
4. lv定義: lv1=中1文型(基本動詞・依頼の初歩) / lv2=依頼・許可・予定(Can, Could,
   going to, How do I) / lv3=経験・比較・所要時間(Have you, 比較級, How long) /
   lv4=雑談(複文・仮定・意見・質問返し)
5. `ja` は日本人が実際に言いたくなる話し言葉。直訳調(「私は〜するところの」等)禁止
6. `alt` は「〜でもOK」「〜の方が自然」の形式で書く
7. `q`(英語で聞かれる形)は、その文が自然な返答になる質問にする
8. LISTENの選択肢: 正解1+「音が似ていて間違えやすいもの」または「状況として
   ありそうな誤解」2つ。無関係なデタラメ選択肢は禁止
9. 英文に使える文字は ASCII + 〜(チャンクの目的語プレースホルダ)のみ

## 禁止事項

- 既存カードの文言変更(誤植修正はOK、その場合ユーザーに報告)
- スキーマへのフィールド追加(必要ならまず `docs/modify_app.md` の手順でアプリ側を先に)
- 教材と無関係なコード変更を同じコミットに混ぜること

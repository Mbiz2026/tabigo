# 月1回ロールプレイの実施手順(どのモデルもこの形式で行う)

目的: ドリルでは再現できない「予測不能な会話」の実戦練習と、進捗の定点観測。
頻度: 月1回。ユーザーから「ロールプレイやろう」と言われたら本書に従う。

## 進行(この順番・この形式で)

1. **準備確認**(日本語で): アプリの利用週数と、最近のセッションで反射速度が
   何秒くらいかを聞く。答えが曖昧でもそのまま進めてよい
2. **場面の提示**: 下の場面リストから3つ提示し、ユーザーに選ばせる
3. **本編**(英語のみ・約10往復): Claudeが現地の人役。以下のレベル調整規則を厳守
4. **講評**(日本語): 下のテンプレート通りに
5. **記録**: `docs/roleplay_log.md` に追記してコミット

## 場面リスト(順に消化。1周したら2周目は「前回の続き」設定で)

1. バーで隣り合った人に話しかけられる(Where are you from? から)
2. 市場の屋台で店主と雑談しながら買い物
3. 電車で乗り合わせた人に日本のことを聞かれる
4. カフェの常連客に「観光?」と話しかけられる
5. 道を聞いたら親切な人で、そのまま立ち話に
6. ゲストハウスの共用スペースで他の旅行者と

## レベル調整規則(Claude側の英語の縛り)

- 1文は12語以内。ユーザーの利用週数+2週分までの文型・句動詞しか使わない
  (週別テーマは docs/add_content.md の表を参照)
- 速いテンポで畳みかけない。1回の発話は1〜2文まで
- ユーザーが10秒以上詰まったら、日本語のヒントを括弧書きで1つだけ出す
  (例: `(「行ったことない」は Have you...? で聞かれたら I've never... が使えます)`)
- ユーザーが日本語で返してきたら、英語での言い方を短く示して続行
- ユーザーの英語に文法ミスがあっても**会話中は指摘しない**(講評でまとめる)。
  意味が取れないときだけ Sorry? と聞き返す(これも練習のうち)

## 講評テンプレート(この3部構成を守る。順番も守る)

```
## できていたこと(3つ)
- (具体的な発話を引用して褒める。抽象的な「良かったです」は禁止)

## 直すともっと通じる点(最大2つ)
- (言った文 → 自然な文 の形で。3つ以上並べない)

## 今日の持ち帰りフレーズ(3つ)
- 会話中に詰まった・言えなかった表現を CHUNK形式で:
  {en:"...", ja:"...", ex:"...", exJa:"..."}
```

持ち帰りフレーズは次回の教材追加時に `index.html` の CHUNK に `pri:1` で登録する
(登録手順は docs/add_content.md)。

## 進捗の定点観測(講評の最後に1行)

以下の3項目を◎○△で記録し、前回との比較を1行で伝える:
- 反応速度(詰まらず返せたか) / 文の完成度(単語の羅列になっていないか) /
  聞き返しスキル(Sorry? / What do you mean? を自力で使えたか)

## 禁止事項

- 実施のたびに形式を変えること(比較できなくなる)
- ユーザーのレベルを大幅に超える語彙・速度で「本場らしさ」を演出すること
- 講評で3つ以上の欠点を並べること(行動科学上、改善点は2つまでが定着する)
